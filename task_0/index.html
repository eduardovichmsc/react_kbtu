5 — Values and References

What happens to the original if you change the copy?
The value in the original changes also.

Why?

What happens when copying a nested object (address) using spread (...) and changing the city?
Will be changed in the original object too.

Why?
The spread operator creates a shallow copy. Nested objects are still passed by reference.

Difference between add and add():
add is a reference to the function itself (treating it as a value).
add() with parentheses invokes (calls) the function, executing its code and returning the result.

8 — Scope

Global scope are declared outside of any functions or blocks, accessible from anywhere in the code.

Function scop declared inside a function, accessible only within that specific function.

Block scope Variables declared inside curly braces {}. They are accessible only within that block.

Difference between var, let, and const:
var is function-scoped and ignores block boundaries. let and const are strictly block-scoped.

9 — Closure

Why can the inner function still access variables from the outer function?
The inner function "remembers" the lexical environment in which it was created, even after the outer function has finished.

10 — Destructuring, Spread and Rest

Difference between spread and rest: They use the same syntax (...) but do different things. Spread unpacks an array or object into individual elements.
Rest collects the remaining elements into a single array.

11 — Optional Chaining and Default Values

Difference between || and ??:
The || operator is triggered by any falsy value. The ?? operator is triggered only by null or undefined. For example, if a value is 0, the || operator will replace it, whereas ?? will keep the 0.
